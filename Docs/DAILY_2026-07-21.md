## 완료한 작업

**네트워크 — 재접속·파트너 보드 미러 (PR #47, #48)**
- 재접속/후입장 시 보드·골드·증강·팀 HP를 다시 동기화하도록 구현했습니다. 과거 스냅샷이 늦게 도착해도 최신 상태를 덮어쓰지 않도록 revision 값을 붙였습니다.
- 파트너 보드 미러가 캡슐 도형 대신 실제 포켓몬 모델을 표시하도록 했습니다. 모델이 없는 경우에는 기존 캡슐로 자연스럽게 대체됩니다.
- ⚠️ 코드·자동 리뷰는 마쳤지만, **실제 2인 접속 환경에서의 검증(강제 끊김 → 재접속 등)은 아직 하지 못했습니다.** 다음 실사 테스트 세션에서 우선 확인할 예정입니다.

**데이터 임포트 — 검증 강화 (PR #51, #52)**
- 스테이지 데이터와 트레이너(적 배치) 데이터를 연결하는 과정에서, 오타가 나도 조용히 넘어가 **적이 0마리인 스테이지가 그대로 저장될 수 있는 문제**를 발견해 막았습니다. 문제가 있으면 임포트 자체를 중단하고 기존 데이터를 보존하도록 바꿨습니다.
- 이 프로젝트에 처음으로 자동 테스트를 붙였습니다(0개 → 16개). 다만 게임 런타임 코드 전체에는 아직 구조적으로 테스트를 붙이기 어려운 상태라, 그 원인과 대응 범위를 문서로 남겨뒀습니다(아래 "어려웠던 점" 참고).

**밸런스 검증 도구 (PR #53)**
- 그동안 엑셀에서 눈으로 확인하던 밸런스 수치(경감계수, 평타 DPS)를 씬에서 버튼 한 번으로 대조할 수 있는 디버그 하네스를 추가했습니다. 시트 값과 실제 코드 계산이 소수점까지 일치함을 확인했습니다.
- 검증 범위는 경감계수·평타 DPS로 한정했습니다(시트에 크리티컬 항목이 없어 그 부분은 대조 대상에서 제외).

**인수인계 문서 정정**
- 이미 완료된 작업(#47, #48)이 인수인계 문서 두 곳에 "미완"으로 남아 있던 것을 발견해 바로잡았습니다. 방치했다면 인수인계 시점에 완료된 작업을 다시 하게 만들 수 있는 오류였습니다.

## 어려웠던 점 + 해결한 방법

- **테스트를 붙이기 어려운 구조**: 게임 로직 대부분이 Unity의 "predefined assembly"에 있어 정식 테스트 프레임워크가 참조하지 못하는 제약이 있었습니다. 우선 의존성 없는 로직만 분리해 테스트 가능하게 만들었고, 전체 구조 개선은 리스크가 커서(Photon 참조를 전부 다시 걸어야 함) 수료 시점 임박까지 미루지 않기로 했습니다.
- **CodeRabbit 무료 플랜 소진**: 오늘 중으로 자동 리뷰 쿼터가 소진되어 이후 PR은 자동 리뷰 없이 진행했습니다(다른 리뷰 수단으로 대체). 플랜 갱신 여부는 팀 논의가 필요합니다.
