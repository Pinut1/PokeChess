## 완료한 작업

**게임플레이 — 롤체식 편의 기능 2건**
- **시작 기물 지급**: 1라운드 진입 시 임의의 1코스트 기물 1마리를 벤치에 무료로 지급합니다. 골드·상점 풀은 차감하지 않으며(보상 지급과 같은 규칙), 2인 협동 구조상 각 클라이언트가 자기 보드에 각각 지급합니다. 중복 지급 가드를 넣었습니다.
- **레벨업 시 자동 승격**: 유닛 정원이 늘어나면 늘어난 만큼 벤치 앞쪽 기물이 빈 보드 타일로 자동 배치됩니다. 기존 배치 경로를 그대로 재사용해서 정원 검사·합체 검사·파트너 보드 미러 동기화가 모두 똑같이 적용됩니다.
  - 검증: 벤치에 1코 4마리를 둔 상태에서 정원을 1 → 3으로 올리자 앞 3마리만 보드로 올라가고 4번째는 벤치에 남는 것을 확인했습니다(에러 없음).

**통신교환 — 설계 반전 확인 및 문서 전면 정합**
- 통신교환의 최종 방향이 6/22에 한 번 기각했던 **즉시 진화 + 필드/벤치/상점 광역 변환** 방식으로 뒤집힌 것을 확인했습니다. 현재 코드는 예전 방식(1마리 핸드오버)이라 재작업이 필요합니다.
- 오후에 해인님이 기획을 확정해주셔서, 오전에 "홀드"로 적어둔 문구를 **"확정 + 구현 브랜치 동결"**로 갱신했습니다. 태욱님 통신기 UI는 기획 대기가 아니라 **master 병합 대기** 상태로 정정했습니다.
- 병합 전에 확인이 필요한 항목은 2건으로 좁혔습니다: ①진화체 시트 스탯이 몇 성 기준인지(계산식 이중 적용 여부) ②매핑 9종 → 7종 삭제 검증.
- 통신 진화체가 다른 유닛보다 강한 것은 **버그가 아니라 설계 의도**임을 확정하고 문서에 명시했습니다(코드의 ×1.5 배율은 걷어내면 안 되는 값).

**스코프 표현 검증·정정 (문서)**
- 인수인계 문서에 애매하게 적혀 있던 항목들을 실제 기획 데이터와 대조해 정정했습니다.
  - **나인이볼부스트 증강**: "스코프 아웃"이 아니라 **이미 구현·동작 중**입니다. 미구현인 것은 진화체 8종 순차 소환 연출뿐입니다.
  - **영웅 스킬(`SK_`)**: 스킬 시트에 해당 행이 0건(기획 미작성)이라 코드로만 동작한다는 근거를 남겼습니다.
  - **보스 전용 기믹**: 기획 역기획서에 보스는 스탯 배수와 배치 좌표만 있고 패턴·페이즈 항목 자체가 없어, 스탯 배수가 최종 스펙임을 확인했습니다(스코프 아웃 근거 확보).
- 방치했다면 인수인계 후 "안 된 줄 알고 다시 만드는" 낭비가 생길 수 있는 항목들이었습니다.

## 어려웠던 점 + 해결한 방법

- **문서와 실제 구현 상태가 어긋나 있었음**: 인수인계 시점이 다가오면서 문서의 "미완/스코프 아웃" 표현이 실제 코드·데이터와 맞는지 하나씩 대조했습니다. 확인 결과 세 항목이 실제와 달랐고, 근거(어떤 시트의 어떤 컬럼을 봤는지)까지 함께 커밋 메시지에 남겨 다음 담당자가 재검증할 수 있게 했습니다.
- **기획이 하루 사이에 확정되면서 문서가 낡음**: 오전에 "기획 확인 필요"로 쓴 내용이 오후 확정으로 무효가 되어, 레포 문서와 노션 페이지를 같은 기준으로 다시 맞췄습니다.
