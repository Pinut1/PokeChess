마지막 미구현이던 골드 전송을 구현했습니다. 이로써 **GDD 통신기 기능(유닛 전송/통신 진화/골드 전송)이 모두 구현 완료**입니다.
- `NetworkManager.SendGoldToPartner(amount)`: 잔액 검증 → **선차감** → 상대 수신 ack, 실패 시 전액 환급 (통신교환과 같은 피어 ack 모델)

- **통신기 UI 담당자**: 전송은 `SendGoldToPartner(amount)`, 피드백은 `GameEvents.OnGoldTransferCompleted / OnGoldTransferRejected / OnPartnerGoldReceived` 구독입니다. 씬의 `GoldTransferDebugTest`(에디터 전용)에 사용 예시가 있습니다.
