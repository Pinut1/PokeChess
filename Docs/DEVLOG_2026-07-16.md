### 1. 확정 증강 7종 + R2 3택1 흐름 구현 완료 (8ef4f30c)
덱기획 v1의 확정 증강 7종을 기준으로 증강 본체와 선택 흐름을 구현하고 에디터 플레이로 전원 효과를 실측 검증했습니다. 기존 목업 증강 4종은 제거했습니다.

- 이자: 이자율 +1(10G당) + 즉시 50G
- 레벨 할인: XP 구매 비용 -2G
- 리롤 환급: 리롤 소모 시 45% 환급
- 채석가: 매 라운드 진화의 돌 1개 지급
- 4코 상점 오픈: 즉시 4코 5슬롯 + 이후 4코 등장 가중치
- 영웅증강 이브이: 진화 잠금·능력치 배수·3성 봇 소환·즉시 지급·리롤
- 영웅증강 파치리스: 탱커 전환·날따름 주입·즉시 지급·리롤

흐름은 `R2 preReward=AugmentChoice` → `RewardManager` → `AugmentManager.OfferChoice()` → 3개 추첨 → 선택·즉시 적용 → 전적 기록 순서입니다. 중복 보유 방지와 최대 3개 보유 가드를 포함했습니다.

구조와 추가 방법은 `Assets/_Project/Docs/AugmentSystem.md`에 정리했습니다. 현재 증강 데이터는 `AugmentCatalog` 코드 정의이며, 기획 엑셀 확정 후 JSON 임포터와 중앙 DB SO 구조로 전환할 수 있습니다.

### 4. DeckDatabase Missing Script 원인 분리 및 수정 PR 생성 (PR #41)
최신 master에서 `Resources/DeckDatabase.asset`이 Missing Script로 표시되는 문제를 추적했습니다.

원인은 `DeckDatabase` 클래스가 `DeckData.cs` 안에 함께 있어 Unity의 ScriptableObject 파일명·클래스 매핑이 실패한 것이었습니다. 기존 수정이 `feature/taewook-sample-deck-ui`에만 있고 master와 `feature/youngwook-sample-deck-backup`에는 없던 것도 확인했습니다.

수정만 master 기준 브랜치 `agent/fix-deckdatabase-missing-script`로 분리했습니다.

- `DeckDatabase`를 `DeckDatabase.cs`로 분리
- 신규 `DeckDatabase.cs.meta` GUID 추가
- `DeckDatabase.asset`의 `m_Script` 참조 재바인딩
- UI·견본덱 기능 커밋은 포함하지 않고 필요한 4개 파일만 구성

**현재 상태:** PR #41은 7/16 `master`에 병합 완료됐습니다. 병합 커밋은 `60cd4282`입니다.
