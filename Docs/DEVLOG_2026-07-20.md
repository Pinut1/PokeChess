## 2. 보드·벤치 시각 프리팹 연결

임시 타일 대신 Hexlands 프리팹을 사용할 수 있도록 `BoardManager`의 배치 설정을 확장했다.

- 전장 `HexTile_Pasture`, 벤치 `HexTile_Desert` 프리팹 연결
- 보드와 벤치의 위치·회전·스케일·간격을 Inspector에서 조정 가능
- 좌표 변환과 `BoardView` 재배치가 프리팹 루트 Transform을 동일하게 반영
- 보드 타일에는 `HexTile`, 벤치 타일에는 `BenchTile`과 드롭용 Collider 구성

## 3. 보드 → 벤치 이동 불가 수정

### 증상

보드 위 기물을 벤치로 끌어 내려도 드롭되지 않았다.

### 원인

벤치 프리팹의 자식 `MeshCollider`가 게임 카메라에서 내려오는 레이를 맞지 않았다. 화면에는 타일이 보이지만 `UnitDragController`의 `RaycastDropTarget()` 결과에는 벤치가 한 칸도 포함되지 않았다.

### 수정

- `BenchTile`이 루트에 Collider가 없으면 자식 Renderer 경계를 기준으로 드롭 전용 `BoxCollider`를 자동 생성
- 시각 메시의 토폴로지와 무관하게 벤치 슬롯 전체가 안정적으로 드롭을 수신하도록 변경

### 검증

- 벤치 9칸 모두 카메라 레이에서 올바른 `BenchTile` 및 슬롯 번호로 판정
- 보드 → 빈 벤치 이동 성공
- 보드 유닛과 점유된 벤치 유닛 교체 경로 유지

## 4. 배치 한도 초과 시 원래 벤치로 복귀

### 증상

배치 가능한 유닛 수를 초과해도 드래그한 기물이 화면상 마지막 위치에 남았다.

### 원인

`BoardManager`가 배치를 거부하면 논리 상태는 원래 벤치 슬롯에 유지되지만 배치 이벤트는 발생하지 않는다. 기존 `UnitDragController`는 드롭 대상이 존재할 때 별도 `BoardView.Resync()`를 호출하지 않아 표현 상태만 어긋났다.

### 수정

- 드롭 성공 여부와 관계없이 매 드롭 종료 시 `BoardView.Resync()` 실행
- 한도 초과 시 `GameEvents.OnUnitPlacementRejected(string)` 발행
- 현재는 Console 경고로 확인하며, 정식 UI에서는 해당 이벤트를 구독해 “배치 불가능” 토스트를 표시할 수 있음

### 검증

- 정원 1 상태에서 두 번째 유닛 배치 거부
- 거부된 유닛이 논리적으로 기존 벤치 슬롯을 유지
- 임의 위치로 이동시킨 Transform이 기존 벤치 좌표로 정확히 복귀(거리 오차 0)
- 플레이어 표시용 거부 사유 이벤트 수신 확인
