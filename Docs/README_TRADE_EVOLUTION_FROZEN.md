## 왜 동결됐나

7/22 오후에 통신교환 기획이 **즉시 진화 + 필드/벤치/상점 광역 변환** 방식으로 확정되면서, 이 브랜치가 구현하던 방식(1마리 핸드오버 계열)과 전제가 달라졌습니다. 재작업이 필요해 진행을 멈췄습니다.

기획 확정 내용은 노션 `🔁 통신교환(통신 진화) 최종 사양 — 2026-07-22` 및 해인님 7/23 일지의 피드백 항목을 참고하세요.

## ⚠️ 해동할 때 반드시 알아야 할 것

### 1. `UnitFactory.cs` / `PokemonUnit.cs`가 master와 충돌합니다

이 브랜치와 **PR #55(2026-07-24)** 가 같은 문제를 **각자 다르게** 고쳤습니다. 둘 다 "진화 시 모델 프리팹이 교체되지 않는" 버그 수정입니다.

| | 이 동결본 (7/22) | master / PR #55 (7/24) |
|---|---|---|
| 위치 | `UnitFactory.RefreshVisual(unit)` (static) | `PokemonUnit.RefreshVisual()` (인스턴스) |
| 구조 | `UnitVisual` **전용 자식 루트**를 만들고 그 안만 비움 | `_visual` 필드로 자식 1개를 직접 관리 |
| 에디트 모드 | `DestroyImmediate` 분기 있음 | `DestroyImmediate` 분기 있음 |
| 추가 | `poolOriginPokemonId` (풀 반환 추적) | 없음 |

**동결본의 `UnitVisual` 전용 루트 방식이 더 낫습니다.** 콜라이더·이펙트 등 다른 자식과 섞이지 않기 때문입니다. 해동 시 이쪽 구조로 통일하는 것을 권합니다.

7/24 시점에는 이 브랜치가 로컬에만 있어 존재를 모른 채 중복 구현이 발생했습니다. 그래서 이 브랜치를 원격에 올려두었습니다.

### 2. 성급 배율이 master에서 바뀌었습니다

PR #55에서 07.23 기획 확정값으로 교체되었습니다.

- 일반 진화 `1.0 / 1.8 / 2.8`
- 특수 진화(진화의 돌·통신교환) `1.0 / 2.0 / 3.0`

기존의 `SPECIAL_EVOLUTION_MULTIPLIER`(일반 배율 × 1.5) 방식은 제거되었습니다. **이 동결본은 옛 방식 기준**이므로, 통신 진화체 스탯 계산 부분을 해동 시 재확인해야 합니다. 특수 3성 기준 4.86 → 3.0으로 크게 내려갔고, 이 하향은 기획 의도가 맞다고 확인받았습니다(7/24).

### 3. 폐기된 브랜치

`feature/trade-evolution-redesign`(7/22 15:58)은 이 브랜치의 **이전 스냅샷**입니다. 코드는 이 브랜치가 상위이며, 그쪽에만 있던 조사 문서는 여기로 옮겨왔습니다. 그 브랜치는 볼 필요 없습니다.
