## 2. 진짜 갭 (필수 — 이거 없으면 7덱이 안 돌아감)

### 🟡 A. 리롤 자원화 (태욱 — 상점) — **구조 변경**
현재 `ShopManager.Reroll()`은 골드 `_rerollCost` 차감 전용. 하지만 Reward Table은 리롤을 **카운트 자원**(RW001~003에서 10개씩 누적 30개)으로 지급하고, 리롤 환급 증강(45%)도 이 자원 기준.
- `RewardKind.Reroll` enum은 **존재하나 `RewardManager.GrantEntry` switch에 case가 없어 지급 안 됨**(누락 버그).
- ShopManager에 무료 리롤 카운터 없음.
- **필요**: 리롤 카운트 필드 + `GameEvents.RerollChanged` + Reroll 시 카운트 우선 소모 후 골드 폴백 + RewardManager Reroll case 추가 + HUD 표시.

### 🔴🟡 B. 증강 시스템 7종 (해인 — 증강 / 일부 영욱·태욱 협조) — **최대 갭**
`AugmentId` enum이 목업 4종, `AugmentFactory`가 나머지 throw. 확정 증강 7종:

| # | 증강 | 구현 난이도 | 주 담당 | 비고 |
|---|---|---|---|---|
| 1 | 이자 (골드×보너스) | ✅ 이미 있음 | 해인 | `GoldInterestAugment` 재사용 |
| 2 | 레벨 할인 (XP 비용↓) | 하 | 해인+태욱 | ShopManager `_buyXpCostGold` 훅 필요 |
| 3 | 리롤 환급 45% | 중 | 해인+태욱 | A(리롤 자원화) 선행 |
| 4 | 파치리스 영웅증강 (서포터→탱커 + 도발부여 + 즉시지급 1 + 전용리롤 3) | 상 | 해인+영욱 | 런타임 role/skill 주입(전투=영욱), 도발스킬 이미 있음 |
| 5 | 이브이 영웅증강 (×1.4 + 진화잠금 + 3성시 봇소환 + 즉시지급 1 + 리롤 3) | 상 | 해인+영욱 | 봇소환 로직 이미 있음. **진화잠금**·×1.4 판정 신규 |
| 6 | 4코 상점 오픈 (5마리 즉시) | 중 | 해인+태욱 | ShopManager 강제오픈 API 필요 |
| 7 | 채석가 (매라운드 돌 1개) | 하 | 해인 | `OnRoundChanged` 훅 → ItemManager.AddStone |

공통 선행: `AugmentData`/`AugmentId` 목업 제거 후 7종 확정, `AugmentFactory` case 교체, R2 preReward=AugmentChoice에서 실제 증강 풀 3택1 오퍼 흐름 배선(현재 `RewardManager`가 AugmentChoice에서 TODO 로그만 남김).

### 🟢 C. 영웅증강 지원 메커니즘 (영욱 — 전투/유닛)
- **이브이 진화잠금**: 영웅증강 활성 시 이브이 머지가 진화체로 안 넘어가고 3성까지 이브이 유지. `PokemonUnit`/`BoardManager.CheckEvolution`에 잠금 플래그.
- **이브이 ×1.4**: 현재 `SpecialEvolutionMultiplier`(×1.5)와 별개 배수. 이브이 영웅증강 전용 스탯 배수 경로.
- **파치리스 런타임 변형**: role Supporter→Tanker 스왑 + 도발 스킬 주입. data 복제 후 변형 or 유닛 오버라이드 필드.
- **봇 소환 트리거 재확인**: 현재 MUTANT 봇은 시너지 tier 기반. 이브이 3성 달성이 돌연변이 tier를 올려 봇이 뜨는지 실제 검증 필요(덱기획: 돌연변이 2~5 단계별 봇).

### 🟢 D. 데이터 저작 (영욱 — 데이터 파이프라인)
- **스테이지 5라운드 표**: R1 Wild(WILD_R1) / R2 Gym(GYM_R2, preReward=AugmentChoice) / R3~4 Gym / R5 Champion(CHAMP_R5). `StageDatabase`에 5행 + Trainer Entry(적 배치 q,r) 저작.
- **보상 테이블 RW001~005**: 골드(6/6/8/10/12) + 리롤(10/10/10/0/0). RW001~003에 `RewardKind.Reroll` 10개씩.
- **포켓몬 풀 축소**: 현재 SO 140종 → 7덱 로스터 ~45종. `shopBuyable` 플래그로 상점 풀은 자동 축소되므로, **비로스터 종 shopBuyable=false 처리 or JSON에서 제거** 결정 필요.
