## 2. 파트너 증강 네트워크 동기화 — PR #43

증강 선택이 로컬 전용이라 `MatchRecord.partner.augments`가 늘 빈 배열이던 것 해소.

- 골드 동기화와 동일한 **Player CustomProperties 미러** 패턴 — RPC와 달리 유예(비활성) 중에도 서버 보존, 재접속·마스터 교체 안전.
- `NetworkManager.SyncLocalAugments` + `AUGMENTS_PROP_KEY`, 수신 시 `GameEvents.PartnerAugmentsChanged`(신설) 발행, 라운드 1 시작 시 잔존 리셋. 송출은 `BoardSyncBroadcaster`가 `OnAugmentSelected` 구독 → 누적 전체 재송출(자가 복구형). `MatchRecorder`가 캐시해 전적에 기록.
- 검증: Clone 증강 2회 선택 → Main 미러 누적 `[ECONOMY_GOLD, ECONOMY_SHOP]` → 세션 종료 후 jsonl `partner.augments` 기록 확인.

## 3. 자뭉열매 (파치리스 영웅증강 v2) — PR #44

증강 별도 티켓 중 첫 전투 신규 메커니즘. **기획 확정 반영**: TFT 블리츠크랭크식 — 전투당 1회, HP 45% 미만 진입 순간 언타겟+행동불능, 매초 maxHP 15% 회복, **완전 회복하거나 다른 아군이 없으면 복귀**.

- `PokemonUnit.hasHeroBerry` → 전투 스냅샷 → `BattleUnit` 상태머신(`TryTriggerSitrusBerry`/`TickBerry`). 과잉피해 즉사 시 미발동(부활 아님), 혼자 남으면 즉시 복귀(무한 언타겟 스톨 없음).
- `BattleManager`: 피해 2경로(일반/화상) 발동 훅, 언타겟 중 행동 스킵(마나는 스턴과 동일하게 충전), **전 대상 선정 제외**(일반 타겟팅/도발 강제·복귀/범위·직선기/날따름 범위/아군 지원/신규 화상). 도발 복귀 스냅샷은 일시 언타겟에 소비되지 않음.
- 검증: 상태머신 8케이스 + 타겟팅 3케이스 에디터 실측 전부 통과.

## 4. 전적창 서버 조회 (Phase 3) — PR #45

전적창이 로컬 jsonl만 표시하던 것을 Supabase 조회로 확장.

- `GameEvents.OnServerMatchesRequested/OnServerMatchesLoaded` 신설 — UI↔업로더 직접 참조 없음.
- `SupabaseMatchUploader`(Phase 2+3): `GET /rest/v1/matches` user_id 필터 + `ended_at` 최신순, snake_case 행/jsonb → `MatchRecord` 역직렬화.
- `UIManager`(태욱 파트, **리뷰 필요**): 전적창 헤더 [로컬][서버] 탭, 서버 목록도 `_recentMatches` 재사용, 상태 문구(불러오는 중/실패/없음), 실시간 삽입은 로컬 탭만.
- 검증: 서버 탭 10건 최신순 + jsonb 역직렬화 정상, 로컬 복귀 정상. ⚠️ ParrelSync는 PlayerPrefs(레지스트리) 공유로 Main/Clone이 **같은 익명 계정** — 클론 테스트 한정 특성, 실기기 무관.
