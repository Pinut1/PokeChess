## 완료한 작업

### 아트·데이터·VFX 통합

- `integration/haein-asset-merge`에 해인 아트 에셋(프리팹·머티리얼·셰이더·스프라이트)과 CoinPanel UI를 통합했다.
- 같은 기준선에는 모델 크기·포즈 정리, 포켓몬 DB v13 및 VFX 60종 등록, FollowMe/VFX 크기 조정, 범위 스킬 VFX의 대상별·중심 스폰 선택, 평타 `attackVfxId` 재생 연결이 포함되어 있다.
- 7/27 인계 기록 기준으로 해당 에셋 통합은 Unity 컴파일 오류 0, 씬 Missing Script/프리팹 0, 스프라이트 배선 정상으로 점검되었다. `.vs/` Copilot 캐시 추적도 제거했다.

### 진화 비주얼 및 성급 배율

- `dca63495`에서 합체 진화와 진화의 돌 장착·해제 시 `PokemonUnit.RefreshVisual()`로 현재 데이터의 모델 프리팹을 다시 생성하도록 수정했다.
- 성급 배율은 일반 진화 `1.0 / 1.8 / 2.8`, 특수 진화(진화의 돌·통신교환) `1.0 / 2.0 / 3.0`의 확정표로 반영됐다.
- 해당 수정은 현 통합 기준선에 포함되어 있으므로, 진화 모델 문제를 별도 기능으로 재구현하지 않는다.

### 전투 8행 단일 전장

- `4be7856a`의 변경을 새 통합 브랜치에 체리픽해 `b0abaa0f`로 반영했다.
- 기존에는 적을 아군과 같은 논리 행에 두고 시각적으로만 `Z+10` 오프셋을 적용했다. 이제 `BoardManager.GetEnemyBattleCoords()`가 적을 rows 4~7, 아군을 rows 0~3에 배치해 4+4행의 연속 전장을 구성한다.
- `BattleManager`의 적 시각 오프셋 분기를 제거해 논리 좌표와 시각 좌표를 일치시켰다. 기존 이동·거리·타겟팅 시뮬레이션은 자유 `HexCoords` 기반이라 변경하지 않았다.
- Play 점검에서 적 rows 4~7 배치와 오프셋 간격 제거를 확인했다.

## 리스크 및 확인 사항

- 현재 변경은 공유 통합 브랜치에 모였지만 `master` 병합은 별도 팀 조율·리뷰 판단이 필요하다.
- “진화 시 모델이 바뀌지 않음”은 `dca63495`로 해결된 보드/상점 비주얼 문제이고, “전투에 들어가면 캡슐로 보임”은 `SpawnVisual`의 별도 미구현 항목이다. 두 문제를 혼동하거나 전자를 재구현하지 않는다.
- 평타 VFX는 접두어 폴백으로 24개 중 22개가 매칭된다. Sylveon의 `Elecric_L` 오타와 Plusle/Minun용 `VFX_Cheer_L` 항목 부재는 해당 평타 이펙트 미재생으로 남아 있다.
- `EnemyLine` 직선 스킬은 폭(`lineWidth`) 데이터가 확정되지 않아 보류 중이다. 현재 구현을 임의로 직선 판정으로 바꾸면 광역기가 사실상 단일 대상이 될 수 있다.
- CodeRabbit 무료 플랜은 소진된 상태로 기록되어 있다. 자동 리뷰 실패 시 쿼터 사유인지 코드 실패인지 구분해 확인한다.
